# Novelty score (0–10)

Score every idea on five criteria, 0–2 each. Show the breakdown, never just the total.

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| **Gap evidence** | Many papers already do this | Partly done, different setting | Searched and found nothing close |
| **New combination** | Same method, same data | New data OR new method | New pairing of fields, populations, or modalities |
| **Underserved population or setting** | Mainstream benchmark only | Some under-studied element | Clearly under-represented group, region, culture or condition |
| **Feasibility** | Data or compute not reachable | Reachable with effort | Data and tools available now |
| **Impact** | Incremental metric gain | Useful to a niche | Changes a practice, enables new work, or answers an open question |

## Bands

- 8–10: pursue; check fast before someone else does.
- 5–7: viable; sharpen the angle to raise gap evidence or combination.
- 0–4: park or kill.

## Rules

- Gap evidence must cite the searches run (tool, query, number of hits, closest 3 papers). Without searches, cap gap evidence at 1 and say so.
- Feasibility depends on the user's real constraints (time, data access, compute). Ask if unknown.
